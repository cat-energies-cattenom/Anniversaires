# Anniversaires
Scripts et fichiers nécessaires à l'envoi de mails pour souhaiter les anniversaires des adhérents
Mode d'emploi
Pour changer le texte ou l'image plus tard :

Se rendre sur le dépôt GitHub.

Clic sur le fichier config.json.

Clic sur l'icône Crayon (Edit).

Modifier le texte du mail (texte_html) ou l'URL de l'image (url_logo).

Clic sur le bouton vert Commit changes... en haut à droite. C'est tout !
